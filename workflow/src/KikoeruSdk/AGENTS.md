# ◉ KikoeruSdk 文件夹

这里是 Kikoeru 的 SDK 文件夹。使用 Saloon，配置了分页与缓存插件。

SDK 文件组织遵守了 Saloon 的规范，分为 `Connectors`、`Dto`、`Enums`、`Requests`。

在编写 Dto 时，参数名须与返回体（JSON）中的键名一致。
